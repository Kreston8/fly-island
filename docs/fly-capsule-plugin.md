# fly-capsule

`fly-capsule` 是一个只调整 fly-island 岛屿几何外观的可选插件。它不会接管颜色、玻璃材质、字体或通知样式，而是继续使用应用本身的外观设置，让胶囊只改变形状相关参数。

## 功能

- 一键在胶囊形状和原始顶部刘海形状之间切换。
- 设置胶囊与屏幕上方的距离，单位为像素，默认 `0px`。
- 分别设置胶囊收起状态和展开状态的圆角圆润度。
- 两个圆角设置使用横向滑杆，拖动时实时预览对应状态的四个角。
- 收起圆角和展开圆角默认相同，互不影响，也不会修改原始刘海形状的圆角。
- 关闭插件或卸载插件后恢复原始顶部刘海形状；颜色和材质始终沿用应用自己的设置。

## 使用

1. 打开「设置 → 插件 → 插件市场」并安装 `fly-capsule`。
2. 打开「设置 → 外观」，在 `fly-capsule` 分组中开启胶囊形状。
3. 按需调整顶部距离、收起圆角和展开圆角。

## 设计说明

`fly-capsule` 复用 fly-island 的胶囊定位、原生窗口命中区域、玻璃质感和实时预览机制。收起与展开圆角使用独立设置，避免插件的胶囊参数污染普通刘海模式。
